# VITAR Sport — USP Generator

Interaktivny generator positioningu, benefitov a kampanoveho copy pre znacky
**Enervit** (sportova vyziva) a **Royal Bay** (kompresne oblecenie).

**Live:** https://jurajgiacko.github.io/vitarsport/

## Co to je

Staticka HTML stranka, ziadny backend, ziadne externe zavislosti.
Vyber znacku, segment, trh a kanal — dostanes positioning, 5 benefitov,
3 diferenciatory voci konkurencii a hotove copy pre 4 kanaly.

- 2 znacky x 7 segmentov x 2 trhy (CZ/SK) x 4 kanaly
- Klik na copy blok = skopiruje do schranky
- Export celeho vystupu vratane CZ+SK naraz, aj ako Markdown

## MVP — co treba doriesit

- `[DOPRAVA]` je placeholder. Doplnit podla aktualnych podmienok dopravy.
- Google Ads texty su koncept, nie hotovy asset. Headline max 30 znakov,
  description max 90 — pred nasadenim rozsekat.
- Data su k 17. 2. 2026. Positioning a diferenciatory platia, ceny a odkazy
  na eventy su spred go-live Royal Bay e-shopu.
